# 🌍 Earthquake Explorer

Aplicación web para la visualización y análisis de terremotos en tiempo real utilizando la API pública del USGS.

El proyecto permite visualizar terremotos sobre mapas interactivos, filtrarlos por fecha y magnitud, guardar favoritos en la nube mediante Firebase y mostrar estadísticas dinámicas mediante gráficas.
