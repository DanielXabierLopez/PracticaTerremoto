# 🌍 Earthquake Explorer

Aplicación web desarrollada en JavaScript para la visualización y análisis de terremotos utilizando la API pública del USGS.

## Objetivos

- Consumo de APIs REST.
- Manipulación dinámica del DOM.
- Programación asíncrona con Fetch y Async/Await.
- Visualización de datos sobre mapas interactivos.
- Gestión de usuarios y datos mediante Firebase.

## Funcionalidades

- Visualización de terremotos en mapas interactivos con Leaflet.
- Filtrado por magnitud y rango de fechas.
- Estadísticas dinámicas.
- Gráficas de análisis con Chart.js.
- Top 10 terremotos de mayor magnitud.
- Sistema de favoritos.
- Autenticación mediante Google.
- Almacenamiento de favoritos en Firebase Firestore.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)
- Leaflet
- Chart.js
- Firebase Authentication
- Firebase Firestore
- GitHub Pages

## API utilizada

USGS Earthquake API

https://earthquake.usgs.gov/
